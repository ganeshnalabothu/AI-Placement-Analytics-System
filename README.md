# AI-Powered Placement Analytics System

## Overview

The AI-Powered Placement Analytics System is a Flask-based web application designed to assist students in placement preparation and career analysis. The platform enables resume-based evaluation, skill analysis, company matching, and placement statistics visualization through an interactive dashboard.

## Features

* Resume Upload and Management
* Student Data Storage using SQLite
* Skill-Based Candidate Analysis
* Company Matching Score Calculation
* Placement Statistics Dashboard
* Student Search and Filtering
* Performance Tracking and Reporting
* Responsive User Interface

## Installation

### Clone the Repository

```bash
git clone https://github.com/ganeshnalabothu/AI-Placement-Analytics-System.git
```

### Navigate to Project Directory

```bash
cd AI-Placement-Analytics-System
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run the Application

```bash
python app.py
```

### Open in Browser

```text
http://127.0.0.1:5000
```
